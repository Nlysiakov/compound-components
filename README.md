Необходимо реализовать компонент формы, используя Compound Components

Требования:

- В файле App.tsx представлен пример использования компонента Form. App.tsx должен остаться таким же, как в исходном репозитории

- При клике на кнопку "Сохранить" в консоль должны выводиться данные формы



Форма должна состоять из следующих компонентов:

- Input – поле ввода, обычный input

- Row – контейнер для инпутов, в него можно положить несколько инпутов и все они должны быть расположены в одной строке и занимать всю ширину родителя (см. скрин)

- Button – кнопка сабмита формы
